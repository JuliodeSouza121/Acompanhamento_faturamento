# Meu Plano Financeiro — versão em branco

App de controle financeiro pessoal. Instala no Android, funciona offline e guarda tudo **só no seu aparelho** (nenhum dado vai para servidor).

## Como hospedar (grátis, ~2 minutos)

### Opção A — Netlify Drop (mais fácil, sem conta obrigatória no início)
1. Acesse https://app.netlify.com/drop
2. Arraste **esta pasta inteira** (ou o arquivo `app-publico.zip`) para a página.
3. Aguarde: ele mostra um endereço `https://algum-nome.netlify.app`.
4. Crie uma conta gratuita quando ele pedir, para o site não expirar.

### Opção B — GitHub Pages
1. Crie um repositório no GitHub e envie os arquivos desta pasta.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

> O endereço fica público para quem souber o link, mas o app começa em branco e os seus dados ficam apenas no seu celular.

## Instalar no Android
1. Abra o endereço no **Chrome** do celular.
2. Menu **⋮ → Instalar app** (ou "Adicionar à tela inicial").
3. Abra pelo ícone. Depois do primeiro acesso ele funciona offline.

## Primeiros passos
1. Aba **Plano**: salário, cartões-benefício, contas fixas e faturas dos cartões.
2. Aba **Início**: veja quanto pode gastar; botão **+** registra cada gasto.
3. **Menus**: supermercado, combustível, parcelas, "posso comprar isso?", histórico e categorias.
4. **Mais**: dízimo, reserva, backup.

## Backup (importante)
Os dados ficam no navegador. Se limpar os dados do Chrome, eles somem. Em **Mais** use **Exportar backup** (arquivo) ou **Copiar backup (texto)**, e guarde.

## Atualizar o app depois
Substitua os arquivos no host. O app pega a versão nova na próxima vez que abrir com internet. Seus dados não são apagados.
